# Legacy Files

This directory contains historical files that are no longer needed for active development but kept for reference.

## Structure

### `debug_docs/`
Debug and bug tracking documents from development:
- `AGENT_1_FIXES.md` - Agent 1 bug fixes
- `DEBUGGING_FINDINGS.md` - Debug session notes
- `FIXES_SUMMARY.md` - Summary of fixes
- `REWARD_FIXES_SUMMARY.md` - Reward shaping bug fixes
- `TRAINING_FILES_DEBUG.md` - Training file debugging
- `TRAINING_READY.md` - Training readiness checklist
- `VISUALIZATION_CHANGELOG.md` - Visualization changes
- `COMPLETION_SUMMARY.md` - Project completion tracking
- `DELIVERY_CHECKLIST.md` - Delivery checklist
- `OVERNIGHT_TRAINING_SUMMARY.md` - Overnight training results
- `README_PARAMETERS.md` - Old parameter documentation
- `CURRICULUM_PHASE1.md` - Phase 1 curriculum notes
- `PARAMETER_OPTIMIZATION_SUMMARY.md` - Parameter tuning summary

### `test_scripts/`
Test and debugging scripts:
- `test_agent_tracking.py` - Agent tracking tests
- `test_clean_output.py` - Output cleaning tests
- `verify_output.py` - Output verification
- `demo_improvements.sh` - Demo improvement script
- `fix_gpu_memory.sh` - GPU memory fix script
- `run_overnight.sh` - Overnight training script
- `run_tests.sh` - Test runner (replaced by run_all_tests.py)

### `logs/`
Temporary log files from development:
- `agent_actions_log.csv` - Agent action logs
- `train_final.log` - Final training logs
- `training_improved.log` - Improved training logs

### Root Legacy Files
Original implementations and notebooks:
- `EnvSim.ipynb` - Original environment simulation
- `PPO with graph attention.py` - Initial PPO implementation
- `train.py` - Legacy training script
- `visualization.py` - Old visualization code
- `single_floor.py` - Single floor implementation

## Note

These files are kept for historical reference only. For current documentation, see the main README.md and other docs in the root directory.
