【核心发现】
═══════════════════════════════════════════════════════════════════════════

1. 用户的批评完全有理 ✅
   ────────────────────
   
   原问题: "你只是说 alpha=0.15 是最好的，但这只是在其他参数固定时。
           可能有更好的组合参数？"
   
   证实结果:
   • ❌ 单参数优化的 α=0.15 确实不是全局最优
   • ✅ 3D 优化找到更好的: α=0.30, β=4.0, γ=0.1
   • ✅ 2D 优化发现不同的局部最优
   
   改进数据:
   • 单参数 α=0.15: 效率 = 0.5434
   • 3D 优化最优:   效率 = 0.5752 (+5.8%)
   • 2D 优化最优:   效率 = 0.5533 
                              (α=0.50, 
                               β=1.0)


2. 参数之间存在重要的相互作用 ✅
   ────────────────────────────
   
   3D 优化证据:
   ┌─────────────────────────────────────────────────┐
   │ 当 Beta = 2.0 时:                              │
   │   最优 Alpha = 0.1  (效率 = 0.5723)            │
   │                                                 │
   │ 当 Beta = 4.0 时:                              │
   │   最优 Alpha = 0.3  (效率 = 0.5752)  ← 全局最优 │
   │                                                 │
   │ 当 Beta = 6.0 时:                              │
   │   最优 Alpha = 0.1  (效率 = 0.5723)            │
   └─────────────────────────────────────────────────┘
   
   关键结论: Alpha 的最优值随 Beta 变化
            不能独立优化各参数!


3. Gamma (拥堵权重) 的影响最大
   ─────────────────────────
   
   对比:
   • γ = 0.1 → 效率 = 0.5752  ✅ 最优 (低拥堵惩罚)
   • γ = 0.2 → 效率 = 0.5434  (中等拥堵惩罚)
   • γ = 0.4 → 效率 ≈ 0.5500  (高拥堵惩罚)
   
   原因: 低 γ 值让 agent 可以并行工作，覆盖更多房间

【为什么要更改参数】
═══════════════════════════════════════════════════════════════════════════

参数变化分析:

1. Alpha: 0.15 → 0.30 (+100%)
   ─────────────────────────
   意义: 增加对距离的权重
   效果: 更积极地清理距离较远的房间
   原因: 在 β=4.0 的风险框架下，增加距离权重不会降低救援人数
        反而能改进覆盖效率

2. Gamma: 0.2 → 0.1 (-50%)
   ────────────────────────
   意义: 减少拥堵惩罚
   效果: Agent 可以更加平行地工作，不会过度分散
   原因: 低拥堵权重让多个 agent 能在同一区域合作
        结果是救援更多人且时间更短

3. Beta: 4.0 → 4.0 (保持)
   ──────────────────────
   意义: 保持风险权重不变
   原因: 4.0 是一个很好的平衡点，不需要调整


【参数的实际含义】
═══════════════════════════════════════════════════════════════════════════

在评分函数中的应用:

    Score(agent, room) = alpha * distance
                        - beta * risk
                        + gamma * congestion
                        + epsilon

alpha (距离权重) = 0.30:
  • 影响对距离的惩罚程度
  • 0.30 表示对远处房间的优先级不会过度降低
  • 相比 0.15 (原值)，允许 agent 走得更远去完成任务

beta (风险权重) = 4.0:
  • 影响对危险房间的重视程度
  • 4.0 表示高风险区域会获得显著优先级
  • 平衡于完成覆盖和管理风险

gamma (拥堵权重) = 0.1:
  • 影响对房间拥堵程度的惩罚
  • 0.1 (低值) 意味着拥堵不是主要考虑因素
  • Agent 可以同时在有人的房间工作，而不是避开

【常见问题】
═════════════════════════════════════════════════════════════════════════════

Q: 为什么 3D 优化只用了 3 个 gamma 值?
A: 时间限制。用了 3×3×3=27 来平衡搜索空间和计算时间。
   2D 优化固定 gamma=0.2 用了更多的 alpha/beta 组合。
   如果需要，可以扩展到更多 gamma 值。

Q: 2D 优化的最优点与 3D 不同，哪个更可靠?
A: 3D 优化考虑了 gamma 的优化，因此应该更可靠。
   2D 优化固定 gamma=0.2，可能错过了 gamma=0.1 的优势。
   2D 优化更多episodes (360) 提供了更详细的 alpha-beta 关系。

Q: 能否在其他布局上使用这些参数?
A: 可能性大，但不保证。建议:
   1. 先在 office/warehouse 上快速测试 (运行 3D 优化)
   2. 如果结果相似，可以使用相同参数
   3. 如果差异大，需要为该布局单独优化

Q: 这些参数是否对所有情况都最优?
A: 不是。最优参数取决于:
   • 布局结构
   • Agent 数量
   • 火灾配置
   • 民众位置分布
   
   我们优化的是 "babycare" 布局的特定设置。

Q: 为什么 gamma 从 0.2 减少到 0.1 效果这么好?
A: 因为 gamma 控制拥堵惩罚。低 gamma 值:
   • 允许多个 agent 同时在同一房间工作
   • 不会因为房间拥挤而避开它
   • 结果是更多房间被及时覆盖
