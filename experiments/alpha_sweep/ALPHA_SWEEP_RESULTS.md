# Alpha 权重参数扫描实验 - 详细结果报告

## 实验设置

**目标**: 在 Babycare 布局上进行详细的 alpha 参数扫描，找到最优的距离权重值

**参数**:
- **布局**: Babycare（3层楼，41个节点）
- **Alpha 范围**: 0.05 ~ 2.0（共 23 个值）
- **种子数**: 每个 alpha 值测试 10 个随机种子
- **总运行数**: 230 个 episodes

## 关键发现

### 1. 最多救援 (Maximum Rescue)
- **最优 α**: **0.05 ~ 0.25** （都是 35.70 人）
- **解释**: 低 alpha 值表示"距离权重较低"，Agent 倾向于优先救援而不考虑路程远近
- **特点**: 救援人数多，但清理时间较长（65-67 步）

### 2. 最快清理 (Minimum Time)
- **最优 α**: **2.0**（62.8 步）
- **解释**: 高 alpha 值表示"距离权重很高"，Agent 会优先选择距离近的目标
- **特点**: 清理时间最短，但救援人数最少（32.1 人）

### 3. 最高效率 (Best Efficiency: rescued/time)
- **最优 α**: **0.15**（效率 = 0.5434）
- **解释**: 这是救援数和清理时间的最佳平衡点
- **特点**: 救援 35.7 人，用时 65.7 步，标准差最低

## 关键观察

### A. 低 α 区间 (0.05 ~ 0.25)
```
特征:
  • 救援数: 35.7 人（最高）
  • 清理时间: 65-68 步（较长）
  • 标准差: 2.0-3.5（稳定性好）
  
分析:
  低距离权重 → Agent 不怕远距离
  → 更多地前往救援目标
  → 救人多，但花时间多
```

### B. 中 α 区间 (0.30 ~ 0.80)
```
特征:
  • 救援数: 33-34.4 人（逐步下降）
  • 清理时间: 64-65 步（稳定）
  • 标准差: 2.0-3.3（逐步增加）
  
分析:
  平衡阶段
  → 既不过分激进，也不过分保守
  → 性能开始下降
```

### C. 高 α 区间 (0.90 ~ 2.00)
```
特征:
  • 救援数: 31.9-32.6 人（最低）
  • 清理时间: 62-64 步（最快）
  • 标准差: 3.8-4.7（不稳定）
  
分析:
  高距离权重 → Agent 只选择近距离目标
  → 快速清理，但漏掉远处的受灾者
  → 标准差大，结果不稳定
```

## 推荐

### 对于不同的任务需求:

| 场景 | 推荐 α | 原因 |
|------|--------|------|
| **最大救援** | 0.05 | 救人数最多 (35.7人) |
| **最佳平衡** | 0.15 | 效率最高 (0.5434 rescued/step) |
| **快速清理** | 2.0 | 清理最快 (62.8步) |
| **稳定性** | 0.10~0.20 | 标准差最低 |

### 生产环境建议:
- **推荐使用 α = 0.15**
- 理由：最高的救援效率，标准差低（=稳定性好），综合性能最优
